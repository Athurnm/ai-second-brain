description: File everything in inbox/ into notes/
---

Process the entire inbox into properly organized notes:

1. List every file currently in `inbox/` (except `README.md` — that one
   stays in place).
2. For each one, propose:
   - a destination path under `notes/`
   - a descriptive kebab-case filename
   - a one-line reason if it's being merged into an existing note instead
     of becoming a new one
3. Show the full plan and **wait for confirmation** before moving anything.
4. Once confirmed: move each file into place, updating its content only as
   needed to read well as a standalone note (add a title if it's missing,
   trim filler), and update any internal links that pointed at the old
   location.
5. Leave `inbox/README.md` in place so the folder is ready for the next
   round of capture.
6. Confirm what moved where.
