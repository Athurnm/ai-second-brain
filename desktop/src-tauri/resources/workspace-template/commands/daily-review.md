---
description: Review your inbox and notes, surface what needs attention today
---

Review the current state of this workspace and give a daily briefing:

1. Read everything currently in `inbox/`.
2. Read any files in `notes/` modified in the last 2-3 days.
3. Summarize open items: things half-started, unanswered questions, loose
   threads worth remembering.
4. Propose the top 3 priorities for today, grounded only in what's actually
   written down here — don't invent context that isn't in the files.
5. For each item still sitting in `inbox/`, offer a one-line suggestion for
   where it should be filed in `notes/`, and offer to do the filing now if
   asked.

Keep the summary short. The goal is orientation, not a full re-read of
everything in the workspace.
